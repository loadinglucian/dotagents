# Code and Callout Patterns

## Code Fence Language Tags

| Tag | Use |
| --- | --- |
| `php` | PHP code |
| `blade` | Blade templates |
| `shell` | Terminal commands |
| `json` | JSON config |
| `xml` | XML/HTML style markup |
| `env` | Environment examples |

## Example Progression

1. Start with simplest working snippet.
2. Add one concept at a time.
3. Introduce alternatives sequentially with transition language.

## Naming Guidance

Prefer realistic names:
- `User`, `Post`, `Comment`, `Order`, `Invoice`, `Flight`

Avoid generic placeholders:
- `Foo`, `Bar`, `Thing`, `Item`

## Callouts

### Note

```markdown
> [!NOTE]
> Helpful context that improves understanding.
```

### Warning

```markdown
> [!WARNING]
> Risk, caution, or security-sensitive guidance.
```

Use callouts sparingly.
